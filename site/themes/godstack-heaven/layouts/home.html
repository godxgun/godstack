Common questions

FAQ

Do I need to use every library?

No. Choose the libraries you need and follow their documented dependencies; for example, Rend integrates with Peak.

Does this page compile C in my browser?

No compiler runs in your browser. The browser demos run C code that was compiled to WebAssembly before publishing.

Is Godstack free to use?

Yes. Project-owned code is released under the MIT License, so you can use, modify and distribute it, including in proprietary applications. Keep the copyright and permission notice with copies of the software. Third-party assets keep their own terms; see the licensing guide for details.

Where do I begin?

Follow the getting started guide, then open the documentation for the library you need.
