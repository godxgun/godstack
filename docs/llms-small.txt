# Godstack: compact setup

Single-header C libraries for platform services, graphics, UI, text, and developer tools. Use only the headers your application needs.

## Setup

For a minimal CPU-only start, copy Grit.h into your project and define GRIT_IMPLEMENTATION in exactly one C translation unit before including it (`#define GRIT_IMPLEMENTATION` then `#include "Grit.h"`). Compile the complete getting-started program with `cc -std=c99 -Wall -Wextra -I. hello.c -o hello`; it prints `value: 42`. Other libraries have their own setup and dependencies; Poof is static header-only and does not use an implementation macro. To build a repository demo, bootstrap with `cc build.c -o build`, then run `./build demo cast`.
