# Symbols

Documentation: https://godxgun.github.io/godstack/symbols/
Description: Search or browse individual Godstack API declarations, separate from the task-oriented guides.


Look up an exact symbol with search, or choose a library below. Declarations and comments come from the public headers; all platform branches are listed, not all promises are portable.

Learning the API? Start with the [library guides](/godstack/docs/). This is the reference shelf, not the lesson plan.
