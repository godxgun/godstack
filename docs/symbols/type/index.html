TypeScratch#

Source: Type.h:110

typedef struct TypeScratch {
	uint8_t *data;
	size_t capacity, used, peak;
	int failed;
} TypeScratch;

Caller-owned temporary-arena view. No allocation or heap fallback. Initialize once per borrowed slice. Operations restore used, retain peak and failed diagnostics. Do not share a view across concurrent/reentrant calls. data must not overlap context, font bytes, output or bitmap storage.

TypeShapedGlyph#

Source: Type.h:220

typedef struct TypeShapedGlyph {
	uint32_t font_id, glyph_id, cluster;
	float x_advance, y_advance, x_offset, y_offset;
} TypeShapedGlyph;

External shaper output, in visual glyph order. cluster is a UTF-8 byte offset in the caller’s logical text, never a glyph index. Positions are pixels, fractional, y down (negate HarfBuzz y values on import). font_id and glyph_id must refer to exactly the face shaped, including glyph 0. Run size uses the same integer-pixel rounding as type_glyph.

type_memory#

Source: Type.h:388

size_t type_memory(const TypeParams *params);

Context reserves memory for all our needs, based on the parameters we pass to it.

NOTE(vasco): First added face becomes primary. A bold+italic face is remembered as bold-italic; a bold face as bold; an italic face as italic. Later adds of the same kind replace that slot. Fallback order is the set_fallbacks list.

Resolve: color emoji prefers a color fallback, then the style face (bold-italic, else italic, else bold), then primary, then fallbacks. A miss draws the primary .notdef (glyph id 0).

Printable ASCII (32..126) and U+FFFD at the current pixel size bypass the LRU. Styled lookups always use the LRU. Changing size drops those slots and warms ASCII again. 0 when params are unusable.

type_layout_shaped#

Source: Type.h:427

TypeError type_layout_shaped(TypeCtx *ctx, const TypeShapedGlyph *run, uint32_t count,
			     float size_px, TypePositionedGlyph *out, uint32_t cap,
			     uint32_t *written, TypeTextMetrics *metrics);

No shaping, bidi, wrapping or fallback is invented here. Use the actual shaper’s glyph order, IDs, clusters and positions. On error, written and metrics describe the completed prefix; atlas/cache may retain that prefix. metrics can be requested with out == NULL (cap still bounds the operation).
