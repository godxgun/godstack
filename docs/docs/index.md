# Library guides

Documentation: https://godxgun.github.io/godstack/docs/
Description: Task-oriented guides for using the Godstack C libraries, with separate symbols and demos catalogs.


Choose a guide below to learn the workflow, storage rules, and limitations of a library.
For individual declarations, use the [Symbols](/godstack/symbols/); to see the code working, open [Demos](/godstack/demos/).
Reading a function list is not the same thing as having an integration plan.
