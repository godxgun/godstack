# Demos

Documentation: https://godxgun.github.io/godstack/demos/
Description: Particle Observatory and 3D Snake, running shared native C code in the browser.

- [Particle Observatory](https://godxgun.github.io/godstack/demos/grit/): A luminous particle field driven by Grit pools, vectors, random numbers, and software rasterization. (browser)
- [Snake](https://godxgun.github.io/godstack/demos/snake/): A native and browser 3D Snake game built with Peak, Grit, and Rend. (browser)
